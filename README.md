# Service Advisor: collecting and preparing service-location data

Python research notebooks for collecting service locations and institution-level information from the Türkiye Services Advisor map, and preparing an Istanbul subset for geospatial research.

The source map includes services for refugees and public services refugees may also use. The project turns map records into structured tables for studying the geography of service provision. It is an independent research workflow, not an official UNHCR data product or a live service directory.

## Workflow

`SA_Scraper.ipynb`:

1. Retrieves the coordinate listing from `/api/services/coordinates`.
2. Uses the returned `id` and `cn` values to request individual service records.
3. Handles connection/time-out errors with retries and increasing delays; honors a numeric `Retry-After` value on HTTP 429 responses.
4. Collects detail records with a thread pool, merges them with the coordinates on `id`, and removes duplicate IDs.
5. Exports the intermediate and combined tables to Excel.

`SA_process.ipynb`:

1. Reads the combined service table.
2. Splits service names into category, city and district fields.
3. Transliterates text using `unidecode` and selects Istanbul-related records.
4. Retains institution attributes and coordinates and exports an Istanbul table.

This demonstrates JSON/API data collection, retry handling, concurrent requests, table joins, deduplication, text normalization and preparation of geospatial research inputs.

## Files and outputs

| File | Purpose |
| --- | --- |
| `SA_Scraper.ipynb` | Coordinate and institution-detail collection |
| `SA_process.ipynb` | Cleaning and Istanbul subset preparation |
| `coord_services.xlsx` | Coordinate listing generated by the scraper |
| `SA_raw.xlsx` | Successfully retrieved detail records |
| `SA_ALL.xlsx` | Merged, deduplicated records |
| `sa_ist.xlsx` | Istanbul subset generated by processing |

Generated workbooks are local research inputs/outputs, not files supplied with this repository. Available fields depend on the source response; the processing notebook expects identifiers, categories, address/contact attributes, `lat`, and `lng` among other fields.

## Use the notebooks

Install the notebook dependencies in a Python environment:

```bash
python -m pip install jupyterlab pandas requests openpyxl Unidecode geopandas matplotlib cartopy
jupyter lab
```

Before running:

- Replace the hard-coded `output`, `input`, and other local directory paths with existing directories on your machine.
- The scraper contains exploratory captured HTTP-header notes before its Python imports. Skip those notes; they are not executable Python and no copied browser cookies are required by the request code. Do not reuse or redistribute captured session headers.
- Run the scraper's executable Python cells in order, then the processing notebook after `SA_ALL.xlsx` exists.
- Add these missing imports to the processing notebook before running it in a fresh kernel:

  ```python
  import pandas as pd
  from unidecode import unidecode
  ```

- Review the manual institution-name assignments to the first three Istanbul rows. They are research-specific edits tied to the original extraction and should not be applied blindly to a new download.

The scraper currently uses ten worker threads. Start with a small selection and lower concurrency when appropriate; respect the source's access conditions and rate limits.

## Scope and limitations

These are exploratory research notebooks, not a packaged scraper. Documentation was checked against the published source; the live service endpoint was not re-scraped for this README update.

Coverage is the set of records returned by the source at collection time, not a verified census of all institutions or operating services. Failed detail requests can be omitted by the inner join, source schemas can change, and service availability must be checked separately. Location points do not establish actual accessibility, capacity or service quality. Transliteration can collapse distinct spellings; preserve source text when exact names matter.
